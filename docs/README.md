# Playbooks

Internes Betriebshandbuch für NoDelay Webdesign, als eigenständige HTML-Seiten (auch als
Claude-Artefakte veröffentlicht, siehe Links unten).

- **`nodelay-betriebssystem.html`** — das Gesamtsystem: Erstgespräch, Bauen mit Claude,
  Freigabe, Live schalten, die zwei Übergabe-Modelle (Kunde übernimmt vs. laufendes Hosting)
  und Preise.
  → [Live-Version](https://claude.ai/artifact/YSPLjv1TrZ4GYj6WSLFa7X)
- **`nodelay-pipeline.html`** — der technische Teil im Detail: GitHub → Netlify → Domain,
  als abhakbare Checkliste für neue Kundenprojekte und für spätere Änderungen.
  → [Live-Version](https://claude.ai/artifact/3XQSpjzwM4rkaUuTB4JK4a)

Einfach im Browser öffnen (keine Installation nötig) oder über die Live-Links aufrufen.
